홍문원 북스토어 — 디자인 및 구매 흐름 체험 버전
제작일: 2026-11-16

1. 실행 방법
압축파일을 모두 풀고 index.html을 Chrome, Edge, Safari 등 최신 브라우저로 열어 주세요.
폴더 안의 파일 위치와 이름을 유지해야 이미지, 스타일과 기능이 정상 표시됩니다.
별도 설치, 빌드, 외부 라이브러리, 인터넷 이미지 연결이 필요하지 않습니다.
파일 직접 열기에서 브라우저가 저장 기능이나 Web Crypto를 제한하면
로그인 창의 '체험 계정으로 시작하기'를 이용하거나 웹서버에 업로드해 실행하세요.
개발자는 Python이 설치된 경우 해당 폴더에서 python3 -m http.server 8000을 실행하고
http://localhost:8000에서 확인할 수 있습니다.

2. 파일 구성
index.html : 메인 페이지, 메뉴, 슬라이더, 섹션과 팝업 기본 구조
style.css : 다크블루/로열블루 디자인, 반응형 레이아웃, 주문서/서재/리더 스타일
scrip.js : 상품 데이터, 검색/정렬, 회원가입/로그인, 장바구니, 포인트, 체험 결제, 서재
img/hero-library.webp : 생성한 서재 히어로 사진
img/hero-ebook.webp : 생성한 전자책 히어로 사진
img/hero-reading.webp : 생성한 독서 공간 히어로 사진
img/hero-study.webp : 생성한 학습 공간 히어로 사진
img/book-01.svg ~ book-08.svg : 직접 디자인한 샘플 도서 표지 8종
img/favicon.svg : 서점 아이콘
IMAGE_PROMPTS.txt : 사진 제작 프롬프트 기록

3. 제공 기능
- 사진 4장 크로스페이드 슬라이더: 6.5초 전환, 이전/다음/정지, 슬라이드 선택
- 사용자 동작 감소 설정 존중 및 비활성 탭에서 자동 재생 중지
- 8개 샘플 상품: 종이책과 전자책 형식 선택, 상세 소개, 미리 읽기
- 제목/설명/저자/분야 검색, 카테고리 필터, 신간/가격/인기 정렬
- 관심 도서, 장바구니 수량 변경/삭제, 배송비 자동 계산
- 브라우저 안에서만 작동하는 회원가입, 로그인, 체험 계정, 마이페이지
- 가입 축하 2,000P, 등급별 1/3/5/7% 적립, 포인트 사용, 누적 금액별 자동 승급
- 결제수단 선택과 주문서, 중복 전자책 구매 방지, 체험 주문 기록
- 체험 결제 직후 내 서재에 전자책 추가
- 4개 장으로 구성된 직접 작성한 샘플 원고, 목차, 글자 크기, 주야간 모드, 책갈피
- 읽던 장 저장, 샘플 전자책 HTML 파일 다운로드
- 모바일/태블릿/PC 레이아웃, 키보드 탐색, 기본 접근성 레이블
- 체험 데이터 초기화

4. 포인트와 배송 계산
리더: 신규 회원, 적립 1%
플러스: 누적 도서 실결제액 100,000원 이상, 적립 3%
프리미엄: 누적 도서 실결제액 300,000원 이상, 적립 5%
블루: 누적 도서 실결제액 500,000원 이상, 적립 7%
적립 기준: 도서 합계에서 사용 포인트를 뺀 금액. 배송비 제외.
적립률: 주문 직전 등급 기준. 적립 포인트는 소수점 버림.
등급 계산: 주문 완료 후 누적 도서 실결제액을 반영해 승급.
배송비: 종이책 합계 30,000원 이상 무료, 미만 3,000원. 전자책은 배송비 없음.
무료배송 기준에는 전자책 금액을 포함하지 않습니다.

5. 꼭 확인할 범위
현재 결과물은 프런트엔드 체험 버전입니다. 실제 요금 청구, 회원 인증,
실물 배송이나 실제 유료 도서 배포 시스템과 연결되어 있지 않습니다.
전시된 도서/저자명/가격/출간정보는 샘플이며 실제 판매 실적이나 독자 리뷰를 표시하지 않습니다.
리더 본문은 기능 점검을 위해 직접 작성한 짧은 샘플입니다.
상품 정보와 샘플 본문이 JS에 들어 있어 유료 원본 보호용으로 사용할 수 없습니다.
전자책 다운로드는 샘플 HTML 형식입니다. EPUB/PDF DRM 서비스가 아닙니다.

6. 실제 서비스 전환 시 필요한 연결
- 서버 기반 회원 인증, 비밀번호 재설정, 이메일 인증, 세션/보안 정책
- 결제대행사 계약 및 서버의 결제 승인 검증과 서명된 웹훅 검증
- 서버에서 주문/포인트/회원등급을 함께 처리하는 원자적 거래와 중복 처리 방지
- 실제 도서 목록과 재고, 주문/배송 관리, 취소/환불 및 포인트 회수 처리
- 결제가 검증된 구매자만 접근 가능한 전자책 저장소와 만료되는 다운로드 URL
- 원본 EPUB/PDF 등록과 필요한 콘텐츠 이용권한/라이선스 관리
- 사업자 정보, 고객센터, 운영 약관과 개인정보 처리방침 확정
이 정적 파일의 장바구니/가격/포인트/보유권한을 실제 결제의 신뢰 근거로 사용하면 안 됩니다.

7. 데이터 저장
localStorage 키: hongmunwon_bookstore_v1
이름, 이메일, 개별 salt와 비밀번호 해시, 주문, 포인트, 관심 도서, 읽던 위치를 저장합니다.
비밀번호 원문은 저장하지 않으며 PBKDF2-SHA-256 120,000회로 처리합니다.
배송지/전화번호/배송 메모는 체험 입력 항목으로만 사용하고 주문 내역에 저장하지 않습니다.
카드번호나 결제 비밀번호를 입력하는 칸은 없습니다.
실제 개인정보나 다른 사이트에서 사용하는 비밀번호를 입력하지 마세요.
여러 기기 동기화, 저장 데이터의 보안 무결성, 실제 유료 콘텐츠 보호는 제공하지 않습니다.
브라우저 저장소를 차단하거나 지우면 체험 계정과 서재 내역도 사라집니다.
푸터의 '체험 데이터 초기화'로 이 사이트의 체험 데이터를 지울 수 있습니다.

8. 수정 위치
서점명/메인 문구/푸터: index.html
메인 컬러: style.css 첫 부분 :root의 --navy, --blue, --cream, --gold
도서 목록/가격/소개: scrip.js의 books 배열
회원등급: scrip.js의 grades 배열
히어로 문구: scrip.js의 slides 배열
전자책 샘플: scrip.js의 chapterTitles, commonChapters, introductions
슬라이드 사진: img 폴더의 hero-*.webp를 같은 이름으로 교체
이미지를 추가할 때는 index.html과 scrip.js의 상대경로를 함께 확인하세요.

9. 확인한 주요 동작
PC 및 375px 모바일 레이아웃에서 가로 넘침 없이 표시됨.
신규 가입 후 리더 등급/2,000P 지급, 로그아웃/비밀번호 로그인 확인.
전자책 15,400원 - 3,000P = 12,400원, 플러스 3%로 372P 적립 확인.
종이책 6권 118,800원 - 2,000P = 116,800원, 리더 1%로 1,168P 적립 및 플러스 승급 확인.
종이책 1권 주문의 배송비 3,000원과 30,000원 이상 무료배송 확인.
체험 결제 즉시 서재 추가, 2장/50% 이어 읽기, 책갈피와 배경/글자 설정 저장 확인.
도서 검색 결과, JS 문법, 파일 참조와 이미지 4장/표지 8종 포함 여부 확인.

10. 디자인 자산
사진 4장은 이 프로젝트를 위해 이미지 생성 도구로 새로 제작했고 WebP로 최적화했습니다.
도서 표지와 아이콘은 텍스트 정확도와 수정 편의를 위해 SVG로 직접 디자인했습니다.
모든 사용 이미지는 img 폴더에 포함되며 원격 이미지 서비스에 의존하지 않습니다.
사용 폰트는 시스템 폰트 우선이며, 설치되어 있으면 Pretendard를 사용합니다.
